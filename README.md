# TexCycle AI — Research Portfolio

**Project ID:** R26-IT-081

TexCycle AI is an AI-powered digital marketplace for upcycling Sri Lanka’s textile waste. It connects buyers and sellers and supports sustainable material reuse.

## Pages
- Home
- Research Domain
- Research Components
- Milestones
- Documents
- Presentations
- About
- Contact

## Research Components
1. Fabric Intelligence
2. Sustainability Intelligence
3. Traceability and Commercial Intelligence
4. Marketplace Predictive Analytics

## Run Locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Visit `http://localhost:8000`.

## Project Structure

- `css/style.css` — Website styling
- `js/main.js` — Navigation and page functionality
- `assets/images/` — Images and diagrams
- `assets/documents/` — Research documents
- `assets/presentations/` — Presentation files
